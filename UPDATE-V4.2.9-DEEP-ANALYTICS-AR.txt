Joudy Game V4.2.9 — First-party Game Analytics

- Vercel serverless endpoints: /api/game.js and /api/player.js.
- Supabase SQL schema: supabase/schema.sql. Run it in Supabase SQL Editor.
- Required environment variables: NEXT_PUBLIC_SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, ADMIN_PASSWORD.
- Keep SUPABASE_SERVICE_ROLE_KEY secret in Vercel Environment Variables. Never place it in browser code.
- Session-scoped random ID only (no cross-session persistent player identifier).
- Coarse device/browser category, language/timezone, screen dimensions, orientation, DPR, referrer host/UTM source, load time.
- Events: session start/end, level start, wins/losses, score updates, aggregate control labels, tab visibility, idle state and JS errors.
- Private test build only: IP is stored for sessions using the matching private test token; ordinary visits are not recorded. No GPS, precise touch coordinates, battery access, device fingerprinting or VPN inference.
- Private dashboard URL: https://YOUR-DOMAIN/panel-k9x2m7p4.html (password required). The URL is not a replacement for authentication.
- Admin reads/deletes are server-side; the Supabase service-role key stays in Vercel environment variables.
