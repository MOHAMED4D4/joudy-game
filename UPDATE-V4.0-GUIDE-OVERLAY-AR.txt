تحديث V4.0 - تحسين واجهة دليل جودي

- إبقاء ساحة اللعب ظاهرة أثناء شرح جودي، دون الانتقال إلى صفحة منفصلة أو تعتيم الخلفية.
- رفع نافذة شرح المستوى قليلًا عن أسفل الشاشة وتوسيعها لتقليل تزاحم الصورة والنص.
- الحفاظ على صورة جودي مربعة بجانب النص مع خط iPhone العريض.
- عند ظهور عدو جديد لأول مرة، تظهر دائرة تحديد حول موقعه داخل ساحة اللعب.
- تنتقل نافذة الشرح إلى الجهة المقابلة لموضع العدو، وتتم محاذاتها رأسيًا بالقرب منه.
- إزالة الرموز التعبيرية من عناوين تعريف الأعداء.
- إصلاح محارف أسطر جديدة زائدة كانت ستسبب خطأ صياغة في GameArena.tsx.

ملاحظة: لم يكتمل التحقق بالبناء (Next.js build) لأن تثبيت الاعتماديات تجاوز المهلة المتاحة. يلزم تشغيل npm install ثم npm run build قبل النشر.
