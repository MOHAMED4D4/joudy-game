تعديل ملء الشاشة:
- أزيل استدعاء Fullscreen API الخاص بالمتصفح من زر ملء الشاشة.
- أصبح الزر يفعّل وضع عرض غامر داخل الصفحة باستخدام CSS، ويعود للوضع العادي عند الضغط مرة أخرى.
- هذا يمنع ظهور رسالة Android Chrome الخاصة بإرشادات السحب للخروج من ملء الشاشة؛ لأن الموقع لم يعد يطلب وضع ملء الشاشة الأصلي من المتصفح.
- تنبيه: وضع CSS لا يستطيع إخفاء شريط عنوان Chrome أو واجهة المتصفح خارج مساحة الصفحة، ولا يمكن للمواقع إزالة تنبيه النظام عند استخدام ملء الشاشة الأصلي.
