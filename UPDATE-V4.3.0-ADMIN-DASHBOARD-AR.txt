Joudy Game V4.3.0 — لوحة تحكم وتحليلات محسّنة

ما الجديد؟
- لوحة إدارة عربية RTL بتصميم متجاوب للموبايل والكمبيوتر.
- نظرة عامة بمؤشرات الجلسات والأحداث والفوز والخسارة ومعدل الفوز ومتوسط مدة الجلسة.
- فلاتر زمنية: آخر 24 ساعة، 7 أيام، 30 يومًا، أو كل البيانات المحمّلة.
- رسوم نشاط يومية وتوزيع الأجهزة والمتصفحات ومصادر الوصول وعناصر التحكم.
- تحليل للمراحل من أحداث level_start و game_win و game_loss الفعلية.
- جدول جلسات قابل للبحث والتصفية، مع نافذة تفاصيل لكل جلسة وسجل أحداثها.
- سجل أحداث قابل للبحث والتصفية وتصدير JSON أو CSV.
- قراءة Supabase بالصفحات مع إجمالي السجلات وحد تحميل أقصى؛ وتظهر ملاحظة عند بلوغ الحد.
- تحسين عرض الأخطاء، تسجيل الخروج، وتوضيح حدود ودقة المؤشرات.

إعدادات Vercel المطلوبة:
- NEXT_PUBLIC_SUPABASE_URL = رابط مشروع Supabase.
- SUPABASE_SERVICE_ROLE_KEY = مفتاح الخدمة السري، يُحفظ في إعدادات Vercel فقط ولا يوضع في الواجهة.
- ADMIN_PASSWORD = كلمة مرور قوية للوحة الإدارة.

قاعدة البيانات:
- الجداول المطلوبة: public.game_sessions و public.player_events.
- نفّذ supabase/schema.sql في SQL Editor إذا لم تكن الجداول قد أُنشئت من قبل.
- أضيفت فهارس اختيارية لتحسين قراءة سجل الأحداث حسب التاريخ والنوع. يمكن تنفيذ schema.sql مرة أخرى بأمان لأن أوامر الفهارس تستخدم IF NOT EXISTS.

رابط اللوحة:
https://joudy-game.vercel.app/panel-k9x2m7p4.html

ملاحظات دقة وخصوصية:
- المعرّف مؤقت ومخصص للجلسة، وليس معرّفًا دائمًا لشخص بعينه.
- في نسخة الاختبار الجانبية: يسجل الخادم IP وUser-Agent عند بداية الجلسة ويعرضهما في لوحة التحكم. لا تجمع اللوحة GPS أو إحداثيات اللمس أو بصمة جهاز.
- معدل الفوز محسوب من أحداث الفوز والخسارة المسجلة فقط.
- متوسط مدة الجلسة يعتمد على حدث session_end، وقد لا يصل إذا أُغلق المتصفح أو انقطع الاتصال.
- لا تعرض اللوحة أي بيانات تقديرية باعتبارها حقائق؛ وتوضح حدود التحميل عند الاقتضاء.
