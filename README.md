# مغامرة التجميع السريعة

لعبة أركيد عربية تضم 30 مستوى موزعة على ست بيئات، مع نظام نقاط وقلوب وتحديات متدرجة وحفظ للتقدم والنتائج.

## تشغيل المشروع

1. ثبّت الحزم باستخدام `npm install`.
2. شغّل بيئة التطوير باستخدام `npm run dev`.
3. افتح العنوان المحلي الذي يظهر في الطرفية.

## تحديث الواجهة

- إزالة خيارات العالم المفتوح وحفل التكريم من مسار اللعب والواجهة الرئيسية.
- إعادة تصميم شاشة البداية بطابع أركيد داكن واحترافي، مع حركة وإضاءة وخلفية شبكية.
- إزالة وصف الأشياء المفضلة والعبارات التعريفية القديمة.
- تحديث دليل النقاط والتحدي بصياغة مباشرة.
- ترتيب أرقام المستويات تصاعديًا داخل كل منطقة من 1 إلى 30.
- تحديث شاشة اجتياز المرحلة إلى رسائل محايدة ومباشرة.
- تقليل الحواف البيضاء داخل ساحة اللعب وتحسين أزرار التحكم.
- تحديث أسماء البيئات لتكون أقل طفولية.

## ملاحظة

تتضمن هذه النسخة إعادة تصميم الواجهة ومسار الأركيد. متجر الملابس والأحذية المدفوع بعملة داخلية وتغيير مظهر شخصية اللعب فعليًا يحتاج إلى تنفيذ مستقل؛ لم أضع أزرار شراء شكلية تدّعي أنها تعمل.
