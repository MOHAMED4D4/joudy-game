# عالم جودي — Joudy's World

مشروع Next.js عربي يجمع بيت جودي التفاعلي مع لعبة الأركيد الأصلية ذات 30 مستوى. هذه النسخة مبنية على لعبة المراحل الأصلية فقط؛ لا تتضمن عالم الإسكندرية المفتوح أو نمط المنصات المنفصل.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

## ما تم تنفيذه في النسخة الحالية

### البيت وعالم جودي
- شاشة رئيسية على هيئة بيت تفاعلي، وتستخدم صورة جودي الأنمي نفسها الموجودة في لعبة المراحل.
- أقسام داخل الموقع: غرفة النوم، المطبخ، الصالة، ركن الحيوانات الأليفة، الخزانة والمتجر، وألبوم المغامرات.
- تفاعلات بسيطة مع جودي، وحالات للجوع والطاقة والمزاج، وإطعام وراحة وأنشطة.
- ركن حيوانات أليفة مع رفقاء قطط يمكن شراؤهم أو اختيارهم بعملة اللعبة المشتركة.
- تغيير ديكورات الغرف، ومتجر ملابس وأحذية، وقطع تجميلية وقطع تمنح مزايا بسيطة.
- استوديو تصوير بسيط يحفظ صورة PNG للشخصية، وألبوم إنجازات أولي.
- مكافأة يومية محفوظة، ومزامنة العملات بين البيت ومراحل الأركيد.

### لعبة الأركيد الأصلية
- الحفاظ على خريطة اللعبة الأصلية ومستوياتها الثلاثين ونظام النتائج.
- اختيار التحكم من الإعدادات بين الأزرار الكلاسيكية والعصا الافتراضية.
- إضافة أزرار القفز والاندفاع والانزلاق، وإزالة جملة الإرشادات السفلية.
- توسيع ساحة اللعب وتلوين أزرار الصوت والإيقاف والعودة بشكل مميز.
- مفاتيح زرقاء نادرة تُحفظ بين المراحل، وإحياء من موضع الخسارة مقابل تكلفة متصاعدة (1 ثم 2 ثم 4 ثم 8)، مع حماية مؤقتة بعد الإحياء.
- مكافآت عملات عند إنهاء المراحل، واستخدام بعض مزايا الملابس والأحذية في الأركيد.

### الصوت
- نطق اسم جودي وردود قصيرة باستخدام محرك الكلام المتاح في المتصفح، مع محاولة اختيار صوت أنثوي عربي من الأصوات المثبتة على الجهاز.
- الاستماع للاعب وإعادة كلامه بصوت المتصفح عند دعم Web Speech Recognition ومنح إذن الميكروفون.
- نداء «جودي» عند بعض الأحداث الصوتية والاحتفال عند إنهاء المرحلة باستخدام Speech Synthesis.

## حدود النسخة الحالية وما يحتاج استكمالًا

- الصوت الحالي مولّد آليًا من المتصفح، وليس تسجيلًا بشريًا حقيقيًا أو تسجيل جمهور بشري. جودة الصوت وأنوثته وتوفر العربية تختلف باختلاف الجهاز والمتصفح. لا يوجد تسجيل صوتي بشري مرفق بالمشروع.
- إعادة الكلام تحتاج متصفحًا يدعم Speech Recognition وإذنًا للميكروفون.
- الملابس تُعرض حاليًا بتأثيرات لونية على صورة جودي الأصلية، وليست نماذج ملابس مرسومة مستقلة. كذلك شخصية البيت صورة أصلية متحركة بحركة واجهة بسيطة، وليست نموذجًا ثلاثي الأبعاد أو شخصية حوار ذكية كاملة مثل تطبيق تجاري.
- رفقاء القطط في هذه النسخة عناصر/أيقونات قابلة للاختيار، وليست نماذج قطط متحركة تتبع جودي في كل غرفة.
- ما زالت تحتاج تنفيذًا مستقلًا: تحديات الزعماء كل خمسة مستويات، مرحلة سرية كاملة بعد المستوى 30، نظام الطقس الديناميكي، شبح أفضل محاولة، مكافآت تفادي العقبات عن قرب، ومناطق جانبية إضافية، وحركات وتفاعلات أعمق للغرف.
- ألبوم المغامرات والإنجازات موجودان بشكل أولي، ويمكن توسيعهما برسومات ومحتوى خاص بكل مجموعة مراحل.
- لا توجد شاشة إهداء أو رسالة رومانسية في نهاية اللعبة.

تُحفظ العملات والمشتريات والتقدم محليًا في متصفح اللاعب على الجهاز نفسه. هذه الحزمة هي ملفات المشروع المعدلة؛ لا تعني أن الموقع المنشور على الاستضافة قد تم تحديثه تلقائيًا.
