# مغامرة التجميع السريعة — Joudy's World

مشروع Next.js باللغة العربية يضم لعبة أركيد من 30 مستوى مع متجر ملابس وأحذية مرتبط باللعب والعملات والتقدم.

## ترتيب التجربة

- أول صفحة عند فتح الموقع هي صفحة `STAGES` وخريطة المراحل، وليست شاشة البيت.
- يظهر وصف اللعبة وملخص التقدم ونمط اللعب والشخصية ونظام التحدي في نفس الصفحة.
- زر «ابدأ اللعب» ثابت أسفل الشاشة ويظل ظاهرًا أثناء تمرير قائمة المراحل.
- زر «الملابس والأحذية» يفتح المتجر كنافذة داخل صفحة المراحل، ثم يعود اللاعب إلى الصفحة نفسها عند الإغلاق.

## الملابس والأحذية

- بطاقات المتجر تعرض رسومات للملابس أو الأحذية فقط، من دون وضع صورة الشخصية داخل كل بطاقة.
- معاينة جودي تتبدل فور اختيار القطعة قبل الشراء.
- توجد أربعة تصاميم ملابس بطبقات SVG شفافة منفصلة، تختلف في القصّة والتفاصيل وليست مجرد فلاتر ألوان.
- توجد خمسة تصميمات أحذية بطبقات SVG منفصلة: حذاء رياضي، جزمة وردية، حذاء مرتفع، جزمة رحلات، وحذاء السحاب.
- كل طبقة مرسومة على نفس لوحة جودي الأصلية (1024×1024) لتتطابق مع مواضع الجسم والقدمين.
- وجه جودي وحجابها وشعرها من الصورة الأصلية ولا يتم استبدال الشخصية عند تغيير الملابس.
- زر «شراء وتجهيز» موجود بجانب معاينة جودي أعلى لوحة العرض.
- الملابس والأحذية المجهزة تظهر في معاينة المتجر وشاشة البيت ومشهد اللعب الفعلي داخل لوحة Canvas، بالترتيب نفسه: الشخصية الأصلية ثم طبقة الملابس ثم طبقة الأحذية.

## العملات والحفظ

- رصيد العملات مشترك بين شاشة المراحل والمتجر واللعب.
- يتم حفظ المشتريات والقطع المجهزة والعملات في `localStorage` على جهاز اللاعب.
- تم ترحيل معرفات بعض القطع من الإصدارات السابقة إلى القطع الجديدة لتقليل فقدان الإطلالة المحفوظة.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

## ملاحظات

- الملابس مرسومة كطبقات ثنائية الأبعاد متراكبة على شخصية جودي الأصلية، وليست نظام ملابس ثلاثي الأبعاد.
- أصوات اللعبة ومؤثراتها القديمة بقيت منفصلة عن نظام الملابس.
- التقدم والعملات محفوظة محليًا على المتصفح؛ لا تتم مزامنتها تلقائيًا بين الأجهزة.
