# عالم جودي الملكي

لعبة تفاعلية باللغة العربية تضم نمط مراحل، وعالماً مفتوحاً ثلاثي الأبعاد، ومنازل متعددة الغرف، ومتجر قطط، واستوديو مكياج، وخزانة أزياء، وحفل تكريم ملكي.

## تشغيل المشروع

**المتطلبات:** Node.js حديث.

1. ثبّت الحزم:
   ```bash
   npm install
   ```
2. انسخ ملف `.env.example` إلى `.env.local` وأضف مفتاح Gemini إذا كانت المزايا التي تستخدمه مفعّلة في نسختك.
3. شغّل خادم التطوير:
   ```bash
   npm run dev
   ```
4. افتح العنوان المحلي الذي يظهر في الطرفية.

## أبرز الإضافات

- واجهات ونصوص عربية بصياغة أكثر رسمية.
- إعادة تسمية المتجر إلى **متجر القطط** وإزالة الاسم والعبارة السابقين المرتبطين بهما.
- منازل ذات ألوان وديكورات وتسميات غرف مختلفة، مع تقسيمات داخلية وطوابق ثانية في المنازل المحددة.
- 18 زياً، وأدوات مكياج مصحوبة بصور مصغّرة، وتطبيق تغييرات المكياج على خامة وجه جودي مع مؤشر فرشاة.
- مشهد حفل تكريم متسلسل: بوابة ملكية، استقبال ليلي، جمهور مرسوم من ألف شخصية، صورة تذكارية بمكافأة 250 عملة، ممر إلى المسرح، عدّ تنازلي، تسليم الكأس ومضات التصوير، ثم رحلة ليلية بليموزين وحراسة حتى القصر.

## ملاحظات

يستخدم مشهد التكريم صورة جودي الأصلية الموجودة ضمن أصول المشروع. جرى فحص صياغة ملفات TypeScript/TSX، لكن لم يُنفّذ بناء Next.js كاملاً في هذه البيئة لعدم اكتمال تثبيت الاعتماديات.
