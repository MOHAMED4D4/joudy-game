# مغامرة التجميع السريعة — Joudy's World

مشروع Next.js باللغة العربية يضم لعبة أركيد من 30 مستوى، ومتجر ملابس وأحذية، وعملات وتقدمًا محفوظًا محليًا.

## ترتيب التجربة

- تبدأ اللعبة بخريطة المراحل `STAGES`.
- زر «ابدأ اللعب» ثابت أسفل خريطة المراحل.
- قلوب جودي الأساسية باللون الأحمر، والقلوب الإضافية باللون الأزرق أسفلها، مع أدوات الدرع والمغناطيس في صف مستقل أثناء اللعب.
- المستوى الأول يحتوي على السحب المشاكسة فقط كأعداء؛ كل اصطدام يخصم قلبًا واحدًا من أصل ثلاثة.

## الفصول والمراحل

- الفصل الأول: المستويات 1–15، مع زيادة تدريجية قوية في سرعة الأعداء وكثافتهم.
- المستويات 2–5 تقدم وحش الرامي بالقوس والسهام والوحش المطارد. ابتداءً من المستوى 5 تظهر أيضًا وحوش مدرعة ومفجّرات بهجوم قريب يمكن تفاديه بالابتعاد.
- من المستوى 5 تتسع ساحة اللعب فعليًا عبر إبعاد الكاميرا، وتزداد مساحة الحركة والمراوغة.
- المستوى 15 مواجهة كبرى مستقلة بزعيم أكبر ورسومات مميزة وأعداء ومقذوفات أشد.
- بعد إكمال المستوى 15، يمكن فتح الفصل الثاني مقابل 40,000 نقطة. قبل إكماله تعرض البوابة تنبيهًا أحمر يطلب إنهاء المستويات حتى 15.
- الفصل الثاني: المستويات 16–30. ترتفع صعوبة الأعداء والسرعة والكثافة تدريجيًا، والمستوى 30 هو مواجهة الزعيم النهائي بأعلى صعوبة.

## أهداف النقاط

| المرحلة | الهدف |
|---|---:|
| 1–6 | 1,000 · 3,000 · 4,000 · 5,000 · 7,000 · 8,000 |
| 7–10 | 8,500 · 9,000 · 10,000 · 12,000 |
| 11–15 | 13,000 · 14,000 · 15,000 · 18,000 · 25,000 |
| 16–30 | تبدأ بـ28,000 وتزيد 3,000 لكل مرحلة حتى 70,000 في المرحلة 30 |

ملاحظة: الهدفان في المرحلتين 7 و8 استُكملا بقيمتين متدرجتين (8,500 و9,000) لأنهما لم يردا ضمن الأرقام المحددة.

## المتجر والأدوات

- المفتاح الأزرق والقلب الإضافي والدرع الدائري والمغناطيس بسعر 500 عملة لكل شحنة أو قطعة.
- الدرع الدائري يفتح عند المستوى الخامس، ويمنح اللاعب 20 شحنة مجانية عند فتحه لأول مرة، ومدة كل شحنة دقيقتان.
- يمكن شراء شحنات المغناطيس وتفعيلها يدويًا أثناء اللعب لمدة 6.5 ثانية.
- واجهة المتجر تستخدم بطاقات أدوات موحدة برسومات وألوان مميزة مع عرض المخزون الحالي.

## الملابس والأحذية

- بطاقات المتجر تعرض رسومات الملابس أو الأحذية فقط.
- معاينة جودي تتبدل فور اختيار القطعة قبل الشراء.
- طبقات الملابس والأحذية منفصلة بصيغة SVG، وتظهر في المتجر والبيت ومشهد اللعب.

## العملات والحفظ

- رصيد العملات مشترك بين شاشة المراحل والمتجر واللعب.
- يتم حفظ المشتريات والقطع المجهزة والعملات والتقدم في `localStorage` على جهاز اللاعب.
- فتح الفصل الثاني يخصم 40,000 نقطة مرة واحدة ويحفظ حالة الفتح.

## التشغيل

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
```

## ملاحظات

- الملابس مرسومة كطبقات ثنائية الأبعاد وليست نظام ملابس ثلاثي الأبعاد.
- التقدم والعملات محفوظة محليًا في المتصفح ولا تتم مزامنتها تلقائيًا بين الأجهزة.
