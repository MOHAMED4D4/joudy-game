# عالم جودي — Joudy's World

مشروع Next.js عربي يجمع بيت جودي التفاعلي مع لعبة الأركيد الأصلية ذات 30 مستوى. هذه النسخة مبنية على لعبة المراحل الأصلية فقط؛ لا تتضمن عالم الإسكندرية المفتوح أو نمط المنصات المنفصل.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

## ما تم تنفيذه في هذه النسخة المعدّلة

### شاشة جودي والخزانة
- أُزيلت محاكاة تطبيق أنجيلا: لا غرف نوم/مطبخ/صالة، ولا إطعام أو نوم أو محادثة أو استماع للميكروفون أو تفاعل صوتي مع الشخصية.
- بقيت شاشة بسيطة تعرض شخصية جودي واقفة، وتعمل كخزانة لتغيير الملابس والأحذية فقط.
- المتجر يعرض صورة جانبية/مصغّرة لكل قطعة، ومعاينة أكبر على الشخصية قبل الشراء، ثم شراء أو تجهيز القطعة.
- رصيد العملات مشترك بين المتجر واللعبة الأصلية، ومكافآت العملات تُضاف عند إنهاء المراحل.
- اختيار التحكم (الأزرار الكلاسيكية أو العصا الافتراضية) موجود في إعدادات شاشة الخزانة.

### لعبة الأركيد الأصلية
- الحفاظ على لعبة المراحل الأصلية ذات الثلاثين مستوى.
- خريطة المستويات تنتقل تلقائيًا إلى المستوى الحالي/التالي المفتوح بدل بدء العرض من أعلى الخريطة.
- أزرار الحركة والقفز والاندفاع السفلية موضوعة جزئيًا خارج حافة ساحة اللعب لتقليل تغطية المشهد، بينما أزرار الصوت والإيقاف والعودة في الشريط العلوي.
- أُزيل زر الانزلاق بالكامل، وبقي القفز والاندفاع.
- أُزيل نطق «جودي» الآلي من المتصفح في الإحياء وجمع العناصر والفوز؛ لن نستخدم صوت AI لأن المطلوب تسجيل بشري حقيقي.
- ملابس الشخصية المختارة تُطبّق على صورة جودي داخل الأركيد عبر التأثير البصري المتاح حاليًا.

## نقاط يجب معرفتها بوضوح
- ملف صورة الشخصية الحالي صورة مسطّحة؛ لذلك تغيير الملابس في هذه النسخة يتم عبر تأثيرات لونية، وليس تبديل طبقات ملابس مرسومة مستقلة. المعاينة والمتجر يعملان، لكن للحصول على ملابس حقيقية بتصاميم مختلفة نحتاج رسومات/طبقات منفصلة للشخصية.
- لم أضع تسجيلًا بشريًا عشوائيًا بدل «جودي»: نتائج البحث العامة التي ظهرت كانت أصواتًا نسائية عامة، وليست تسجيلًا يقول «جودي». لا يصح تركيب صوت غير مطابق أو الادعاء بأنه تسجيل الاسم. نحتاج ملف تسجيل بشري واضح ومصرّح باستخدامه، ويمكن إضافته لاحقًا إلى ملفات الصوت.
- بعض الإضافات الكبيرة التي سبق الاتفاق عليها ما زالت تحتاج تنفيذًا منفصلًا داخل اللعبة، مثل زعماء كل خمسة مستويات، المرحلة السرية، شبح أفضل محاولة، الطقس الديناميكي، مناطق الاستكشاف الجانبية، وصناديق المكافآت النادرة. لم أعتبرها مكتملة لمجرد وجودها في الخطة.
- تُحفظ العملات والمشتريات والتقدم محليًا في متصفح اللاعب على الجهاز نفسه. هذه الحزمة ملفات مشروع؛ لا تعني أن الموقع المنشور على الاستضافة تم تحديثه تلقائيًا.
