Joudy Game — تحديث V4.3.2 Analytics Pro

التغييرات:
- تحديث بصري احترافي للوحة التحكم القديمة مع الحفاظ على مسارها ووظائف تسجيل الدخول والتصفية والتصدير.
- إضافة رسوم توزيع الشركات المصنّعة وموديلات الأجهزة ضمن تحليلات الأداء.
- حفظ الشركة والموديل ونظام التشغيل وإصداره ونوع الجهاز ومصدر المعلومة في game_sessions.
- إضافة حدث device_details لتحسين بيانات الأجهزة عبر User-Agent Client Hints عند دعم المتصفح.
- إضافة ملخص عربي للجلسة أعلى نافذة التفاصيل.
- عرض واجهة الشركة المصنّعة (مثل One UI / HyperOS) على أنها غير متاحة من المتصفح بدل التخمين.
- تحديث schema.sql بإضافات آمنة على الجداول الحالية باستخدام ADD COLUMN IF NOT EXISTS.

ملاحظات التثبيت:
1) نفّذ محتوى supabase/schema.sql في Supabase SQL Editor.
2) ارفع ملفات المشروع إلى GitHub ثم أعد النشر على Vercel.
3) لا تغيّر متغيرات البيئة الحالية: NEXT_PUBLIC_SUPABASE_URL وSUPABASE_SERVICE_ROLE_KEY وADMIN_PASSWORD.
4) التحسينات الجديدة تظهر للجلسات الجديدة فقط بعد موافقة التحليلات الحالية. البيانات القديمة لا يمكن استنتاجها بأثر رجعي.

حدود المتصفح:
- Client Hints قد توفر موديلًا وإصدار منصة على بعض متصفحات Chromium/Android فقط.
- iOS ومتصفحات أخرى قد تحجب الموديل أو إصدار النظام.
- الويب لا يكشف عادةً إصدار One UI أو HyperOS؛ لا يتم تخمينه.
- لا يجمع هذا التحديث IP خامًا أو GPS أو إحداثيات نقر أو بصمة دائمة.
