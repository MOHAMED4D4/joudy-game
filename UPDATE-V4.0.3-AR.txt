تحديث لعبة جودي — V4.0.3

1) تجربة اللمس
- تعطيل تحديد النصوص والنسخ وقائمة الضغط المطوّل داخل اللعبة، ومنع سحب الصور والرسومات كأنها صفحة ويب.
- إبقاء التحكم باللمس والسحب داخل ساحة اللعب دون تغيير.

2) الخسارة والخروج
- إعادة تصميم شاشة «انتهت المحاولة» بواجهة مستقلة تعرض النتيجة والتقدم نحو هدف المرحلة والإحصاءات وأزرار الإنقاذ وإعادة المحاولة والعودة للخريطة.
- زر العودة إلى خريطة المراحل من شاشة انتهاء المحاولة ينفذ مباشرة دون نافذة تأكيد.
- تأكيد المغادرة يظل موجودًا في استراحة جودي وزر الباب فقط، مع خيار متابعة اللعب أو الخروج.

3) تقسيم الفصول والبوابات
- الفصل الأول: المستويات 1–15.
- الفصل الثاني: المستويات 16–20، يفتح بعد إكمال المستوى 15 مقابل 40,000 نقطة.
- الفصل الثالث: المستويات 21–25، يفتح بعد إكمال المستوى 20 مقابل 65,000 نقطة.
- الفصل الرابع: المستويات 26–30، يفتح بعد إكمال المستوى 25 مقابل 55,000 نقطة.
- لكل فصل حالة فتح مستقلة محفوظة، ولا يمكن بدء مستوياته قبل فتح بوابته.

4) الوحوش وأجواء الفصول
- الفصل الثاني: وحوش ظلّية بأشكال الحارس والعدّاء والوحش الضخم والزعيم.
- الفصل الثالث: وحوش بلورية وخضراء بأشكال مختلفة وحارس خاص في المستوى 25.
- الفصل الرابع: وحوش نارية/قلعية بأشكال مختلفة، مع الزعيم النهائي في المستوى 30.
- إبراز حراس المستويات 20 و25 على خريطة المراحل وإظهار عناوين مواجهاتهم داخل اللعب.
- تحديث رسائل التوجيه للمستويات 20 و21 و25 و26 وما بعدها بما يناسب العالم الجديد.

5) الموسم القادم والإنجازات
- تحريك النقاط البيضاء داخل بطاقة «السيزون القادم قريباً» وإضافة حركة لطيفة للقفل مع بقائه مغلقًا.
- تطوير صفحة الإنجازات إلى بطاقات أوسمة مصوّرة بخمس درجات لونية، مع تمييز المكتسب والمقفل.

6) المتجر
- التأكد من ربط صور SVG المخصصة للمفتاح والقلب الإضافي والدرع الدائري والمغناطيس ببطاقات المتجر.
- تبقى أسعار الأدوات الأربع 500 عملة لكل أداة/شحنة، مع إظهار المخزون الحالي.

7) التحقق
- تم فحص الصياغة البرمجية لملفات TypeScript وTSX المعدّلة.
- تم التحقق من صلاحية ملفات SVG التسعة للمتجر والأوسمة، والرسومات المضمّنة للوحوش الجديدة.
- لم يتم تشغيل Build كامل في بيئة التعديل لعدم وجود اعتماديات المشروع محليًا؛ يجب تنفيذ npm install ثم npm run build قبل النشر النهائي.
